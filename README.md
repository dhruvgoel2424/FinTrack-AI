# AI Money Mentor

# Problem Statement

Managing personal finances is challenging for many students and working professionals. Most existing expense tracker applications only allow users to manually record transactions and display basic reports. They do not provide personalized financial guidance, predict future spending, detect unnecessary subscriptions, or help users make informed financial decisions. As a result, users often struggle with budgeting, overspending, missed bill payments, and understanding their overall financial health.

This project aims to develop **AI Financial Coach**, an intelligent personal finance management platform that goes beyond traditional expense tracking. The system will use Artificial Intelligence to automatically extract expense data from receipts using OCR, analyze spending patterns, predict future expenses, generate personalized budget recommendations, detect recurring subscriptions, remind users about upcoming bills, and calculate a monthly Financial Health Score. Additionally, it will provide AI-powered financial insights, investment suggestions based on user goals and risk preferences, and a voice-enabled assistant for quick financial queries.

The objective is to build a smart, user-friendly financial assistant that helps users improve their financial habits, make better spending decisions, and achieve their savings and investment goals through real-time analytics and AI-driven recommendations.
